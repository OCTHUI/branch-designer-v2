# 国际化配置持久化 - 使用说明

## 📋 功能概述

已将 branch-designer-v2 的国际化配置从纯内存模式升级为**文件持久化模式**，支持：

- ✅ **启动加载**：系统启动时自动从文件加载语言包
- ✅ **实时保存**：新增/修改/删除词条时自动更新文件
- ✅ **批量导入**：批量导入操作实时写入文件
- ✅ **降级兼容**：后端服务未启动时自动降级到内存模式

## 💡 使用方式

### 方式一：UI 操作（推荐）

1. 打开 http://localhost:8080
2. 点击左侧边栏的 **🌐 国际化配置** 图标
3. 进行以下操作：
   - **添加词条**：点击「添加」按钮 → 编辑 → 自动保存
   - **批量导入**：点击「批量导入」→ 选择 .ts/.js 文件 → 导入 → 自动保存
   - **批量删除**：选中词条 → 点击「批量删除」→ 自动保存
   - **编辑词条**：点击编辑图标 → 修改 → 失焦自动保存

所有操作都会**实时同步到文件**！

### 方式二：API 调用

```bash
# 读取语言包
curl http://localhost:3080/api/locale

# 保存完整语言包
curl -X POST http://localhost:3080/api/locale \
  -H "Content-Type: application/json" \
  -d '{"zh-cn":{"KEY":"值"},"en":{"KEY":"Value"}}'

# 更新单个词条
curl -X PATCH http://localhost:3080/api/locale/zh-cn/MY_KEY \
  -H "Content-Type: application/json" \
  -d '{"value":"新值"}'

# 批量导入
curl -X PATCH http://localhost:3080/api/locale/zh-cn/batch \
  -H "Content-Type: application/json" \
  -d '{"entries":[{"key":"KEY1","value":"值 1"},{"key":"KEY2","value":"值 2"}]}'

# 批量删除
curl -X DELETE http://localhost:3080/api/locale/zh-cn/batch \
  -H "Content-Type: application/json" \
  -d '{"keys":["KEY1","KEY2"]}'
```

## ⚠️ 注意事项

### 1. 服务依赖

后端服务需要保持运行，否则前端会降级到内存模式（刷新丢失数据）。

**检查服务状态：**
```bash
curl http://localhost:3080/api/locale
```

### 2. 端口占用

如果 3080 端口被占用，修改 `server.js` 中的 `PORT` 常量，并同步修改 `LanguageConfig.vue` 中的 `API_BASE`。

### 3. 数据备份

建议定期备份 `custom-locale.json`：
```bash
cp packages/element-ui/src/locale/custom-locale.json \
   packages/element-ui/src/locale/custom-locale.json.bak.$(date +%Y%m%d)
```

### 4. 与默认语言包的关系

- `zh-cn.js` / `en.js`：系统默认语言包（组件内置文本）
- `custom-locale.json`：用户自定义语言包（持久化）

**优先级**：`custom-locale.json` > 默认语言包

## 🔧 开发模式

### 仅前端开发（无持久化）

如果只想测试前端功能，可以不启动后端服务。前端会自动降级到内存模式，控制台会显示：

```
⚠️ 无法连接持久化服务，使用内存模式
```

### 生产环境部署

生产环境建议：
1. 使用 PM2 管理后端服务
2. 配置 Nginx 反向代理
3. 设置语言包文件权限为只读（运行时）
4. 定期备份语言包

## 🐛 故障排查

### 问题 1：前端提示「无法连接持久化服务」

**检查：**
```bash
# 1. 服务是否运行
ps aux | grep server.js

# 2. 端口是否监听
netstat -tlnp | grep 3080

# 3. API 是否可访问
curl http://localhost:3080/api/locale
```

**解决：** 重启后端服务

### 问题 2：保存失败

**检查：**
```bash
# 文件权限
ls -la packages/element-ui/src/locale/custom-locale.json

# 磁盘空间
df -h
```

**解决：** 确保文件可写，磁盘有空间

### 问题 3：导入的词条未显示

**可能原因：**
- 文件格式不正确（应为 .ts/.js，包含 `KEY: 'value'` 格式）
- 语言包未刷新

**解决：** 刷新页面或重新加载语言包
